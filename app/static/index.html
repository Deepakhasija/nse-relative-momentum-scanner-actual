Required CSV format and calculation notes

Required columns (case-insensitive): symbol,date,close,volume,market_cap_cr. One row per stock per trading day. Dates should be YYYY-MM-DD. Provide at least 201 trading sessions per stock. The latest row is treated as the current session.

3M return = latest close / close 63 trading sessions earlier − 1. 200 DMA = average of the latest 200 daily closes. Average turnover = mean(close × volume) over the latest 20 sessions, converted to ₹ crore. Market cap is supplied in ₹ crore and assumed current as of the data date.

The top 20% is ranked among stocks that pass all eligibility filters. Percentile uses (N − rank + 1) / N × 100. This is a price-return ranking, not RS versus Nifty. Corporate-action-adjusted closes are strongly preferred.

2. Eligibility and ranking settings

200 DMA condition is fixed: latest close must be above the 200-day simple moving average. Turnover uses 20-session average of close × volume.
